# Country Project Game

人が互いを理解するための想像力を育てることを目指した、架空の国づくりシミュレーションゲームです。

## 現在の試作版

- 小さな町を歩ける
- PC: 矢印キー / WASD
- スマホ: 画面左下の方向ボタン
- 住民3人に近づいて話しかけられる
- 住民の声を聞いたあと、新しい学校を建設できる
- 国のお金、人口、教育、環境、自由時間が変化する
- 教育・環境・働き方・税金・技術の5分野の方針を変更できる
- 春夏秋冬と年が進む
- 国の状態に応じた小さな出来事が起きる
- 国の歴史が記録される
- ブラウザのlocalStorageに自動保存される

## 操作

### PC

- 移動: 矢印キー / WASD
- 話す: E
- 方針: P
- 歴史: H
- 学校建設: B（条件を満たした後）

### スマホ

画面上の方向ボタン、話すボタン、方針・歴史ボタンを使用します。

## データ設計

`src/data/` に、政策・イベント・30年後の称号候補などをデータとして分離しています。
今後、ゲーム本体からこれらのデータを読み込む形へ段階的に移行します。

## 公開

GitHub Pages用のワークフローを `.github/workflows/pages.yml` に追加しています。
GitHubの Settings > Pages で Source を GitHub Actions に設定すると公開できます。

## プライバシー方針

このリポジトリには、開発者の本名・住所・メールアドレス・勤務先・家族情報などの個人情報を含めません。

ゲーム内の人物名や国名も、実在個人を特定しない架空の情報を使用します。

APIキー、パスワード、アクセストークンなどの秘密情報もコミットしません。
